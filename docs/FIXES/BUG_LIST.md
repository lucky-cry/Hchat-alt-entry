## 2. 归类提示（填完看这一列）

| 症状 | 大概率原因 | 修的地方 |
|---|---|---|
| 功能完全没反应，日志有"安装失败/未找到类/DexFinder为空" | 微信新版本改了混淆，DexKit 定位失败 | `dexkit/DexFinder.java` 或该功能内的定位条件 |
| 入口在、点了没反应 | Hook 装了但目标方法签名变了 | `hooks/items/<功能>/` |
| 行为不对（比如限制没生效、UI 不出现） | 逻辑分支没覆盖新版本路径 | 功能包内 + 逆向证据 |
| 微信崩溃 / 卡顿 | Hook 打到不该打的方法，或主线程阻塞 | 先回滚该功能开关，再定位 |
| 设置页打不开 / 版本号不对 | 构建或安装问题，不是代码问题 | 先确认装的是哪个包 |

## 3. 日志怎么抓（每次复现后立刻抓，别重启微信）

1. **LSPosed 日志**：LSPosed → 底部「日志」→ 右上角搜索 `Hchat`。
   模块所有错误日志都走 `XposedBridge.log`，带 `[Hchat:<模块/功能名>]` 前缀。
2. **命令抓**（有 root 时，Termux 里）：
   ```sh
   su -c "logcat -d -v time | grep -i hchat" > /sdcard/Download/hchat-log.txt
   ```
3. 抓完把**相关那几行**贴进清单，不要整份日志（太长）。
